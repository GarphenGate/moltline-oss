# Summary Template

*Free gateway skill from the Tutoring Center Admin bundle by GarphenGate.*

The after-session note parents forward to each other: what we covered, what moved, what's next — evidenced, warm, ninety seconds to read.

## Procedure

1. **Take the session basics:** student first name, subject, date, and whatever the tutor jotted — shorthand is fine.
2. **Draft the three-part note:** covered (specific topics, named materials), what moved (one concrete thing the student did in session that shows progress — the note's engine), next time (the plan in one line).
3. **If the notes contain no concrete evidence,** the what-moved line becomes an honest "we worked through X; I'll report a milestone as soon as one lands" — and the skill returns the one question to the tutor that would produce evidence next time.
4. **Keep it under 120 words,** warm, jargon-free, and written knowing the parent may forward it to the other parent or a grandparent.
5. **Return the draft** for the user to check names and send from the center's own channel.

Output contract:

```
AFTER-SESSION NOTE — <student first name>, <subject>, <date>
---
Covered: <specifics>
What moved: <evidenced gain | honest placeholder>
Next time: <one line>
---
<assembled note, under 120 words>
```

## Rules

- Never inflate: no "amazing progress" without the concrete thing that shows it; honest beats glowing every time a parent compares notes to results.
- Never include labels, comparisons to other students, or speculation about difficulties — observations only, parent-visible by definition.
- Never send the note; the user checks names and details and sends it.

## Degradation

Given only "good session": produce the covered-only honest version plus the two questions that would make tomorrow's note strong — and say plainly that evidence, not adjectives, is what justifies the fee.
