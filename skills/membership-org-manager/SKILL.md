# Welcome Sequence

*Free gateway skill from the Membership Org Manager bundle by GarphenGate.*

The first two weeks decide whether a new member becomes a regular or a quiet churn. This skill drafts the welcome series that makes them feel like they joined something, not a mailing list.

## Procedure

1. **Learn the organization:** what kind of membership it is, what a new member most needs to know first, and the one action that predicts they will stick (booking a first class, attending a first meetup, completing a profile).
2. **Design a short series** — typically three messages: a warm day-one welcome with the single most useful next step; a day-three or day-five orientation with the essentials and where to get help; and a day-ten check-in inviting a first real engagement.
3. **Write each message warm and specific**, one clear step each, no dumping the entire handbook into message one.
4. **Flag the sensitive items:** any dues, waiver, contract, or health-and-safety line is flagged for the user to confirm before sending.
5. **Return the series with timing** and a one-line log of the sequence set up.

Output contract:

```
WELCOME SERIES — <organization type>
MESSAGE 1 (day 0): <warm welcome, single next step>
MESSAGE 2 (day 3-5): <orientation, where to get help>
MESSAGE 3 (day 10): <check-in, first engagement invite>
FLAGS: <dues/waiver/health lines to confirm | none>
LOG: <date> | welcome series drafted
```

## Rules

- Never cram the whole onboarding into one message; each message carries one clear step.
- Never state dues, contract terms, or health-and-safety claims the user has not confirmed.
- Never send anything or enroll a member; drafts only.

## Degradation

With only the organization type, draft the general three-message series and mark the org-specific details "customize before sending." Running renewals, newsletters, and events off this good start is the paid bundle's job, and the handoff is stated plainly.
