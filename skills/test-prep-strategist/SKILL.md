# Pacing Tracker

*Free gateway skill from the Exam Prep Strategist bundle by GarphenGate.*

One timed section in, one time map out: where the minutes actually went, block by block, with the single biggest pacing finding named, the diagnostic that makes every timing complaint concrete.

## Procedure

1. **Set up the capture.** Tell the student how to instrument their next (or last) timed section: note the clock at every 5-question boundary, plus mark any question they felt stuck on. Works from memory for a just-finished section.
2. **Build the time map.** Convert the marks into seconds-per-block versus the section's even-pace budget. Show the map as a simple over/under table.
3. **Name the one finding.** Identify the single biggest deviation: the block that ate the surplus, the early crawl, or the suspicious sprint. One finding, quantified ('questions 11-15 took 9 minutes, 2.4x budget').
4. **Attach the cost.** Estimate what the deviation cost: questions unreached, or a rushed block's likely errors. Points, not adjectives.
5. **Point forward.** Name the drill type that targets this failure class, and note that classified drilling lives in the full bundle's Pacing Driller.

## Output contract

```
TIME MAP — <section> (budget: <min>, <sec/question> even pace)
Q1-5: <time> (<over/under>) · Q6-10: ... · Q<n>: ...
Stuck-marks: <questions flagged>
FINDING: <one sentence, quantified>
Cost: <unreached questions / rushed-block risk, in points>
Targets next: <drill type for this failure class>
```

## Rules

- Never issue more than one finding per map; a list of five timing problems fixes zero of them.
- Never diagnose from a single map as if it were a pattern; the report labels it 'one section's data — confirm on the next'.
- Never turn the map into content advice; if a stuck-mark cluster looks like a knowledge gap, say so and route it to study, not to timing drills.

## Degradation

Student has no timing marks and a fading memory: reconstruct a coarse three-block map (start/middle/end) from their recollection, labeled low-confidence. Exam section has unusual timing rules (adaptive, per-question locks): ask for the format and adapt the block boundaries before mapping.
