# Post Repurposer

*Free gateway skill from the Social Strategist bundle by GarphenGate.*

One idea in, three platform-native posts out — each with its own hook, its own format, and no copy-paste smell.

## Procedure

1. **Take the source**: a post that worked, a draft, or a raw idea in a sentence. Extract the core: the claim, the example or proof, and the feeling it lands on. Three lines.
2. **Confirm the three target platforms** from the user's actual set; never assume. Different platforms get different jobs: one gets the argument, one gets the story, one gets the visual or list treatment.
3. **Rebuild natively per platform**: distinct opening hook (never the same first line twice), format that matches platform reading behavior (thread or carousel structure, short-video beat sheet, single text post with a reply-bait close), and length tuned to each.
4. **Angle-shift at least one version**: same core, different entry point (the mistake version, the how-to version, the story version) so the three posts don't cannibalize each other for overlapping audiences.
5. **Label what each needs** (image, clip, formatting) and hand all three over as drafts.

## Output

```
REPURPOSE — core: <claim in one line>
1. [<platform> — <format>] <full draft> — needs: <asset or none>
2. [<platform> — <format>] <full draft> — needs: ...
3. [<platform> — <format>] <full draft> — needs: ...
Angle map: <which version takes which entry point>
```

## Rules

- Never ship the same first line on two platforms; if two hooks converge, rewrite one from a different mechanic.
- Never stretch the idea past what the source supports; a thin idea gets one strong post and a note saying so, not three padded ones.
- Each version must name its platform-native format; "the same text, shorter" is not a format.
- Must not invent results, numbers, or story details absent from the source idea.

## Degradation

With no platform set stated, produce three format-labeled versions (short text, thread/carousel, 45-second script) and let the user map them to platforms. With a source post that flopped, first diagnose in one line why (hook, timing, fit), fix that in all three versions, and say what changed.
