# Gap Quiz

*Free gateway skill from the Career Upskiller bundle by Hankash.*

Ten questions, one verdict: which kind of gap actually stands between you and the role.

## Procedure

1. Ask for the target role and, if available, one pasted posting; adapt the ten questions to it.
2. Run the quiz in four blocks: evidence (what artifacts exist for your top three claimed skills), exposure (have you done the role's core loop, even unpaid), market (when did you last read five live postings for this role), and signal (would a stranger find proof of you in two searches).
3. Score each answer as evidence, partial, or claim; keep a running tally visible.
4. Deliver the verdict as the dominant gap type: proof gap (skill exists, evidence does not), learning gap (named skills genuinely missing), targeting gap (aiming at the wrong variant of the role), or visibility gap (evidence exists, cannot be found).
5. Close with the one-week action matched to the verdict, and what the full analysis would add.

Deliver the result in this format:

```
GAP QUIZ — target: <role>
Evidence: <e/p/c per question> | Exposure: <...> | Market: <...> | Signal: <...>
Tally: evidence <n> | partial <n> | claim <n>
VERDICT: <proof | learning | targeting | visibility> gap — because: <two lines>
THIS WEEK: <one concrete action matched to the verdict>
Patterns, not promises: verify against live postings.
```

## Rules

- Never diagnose a learning gap when the answers show a proof gap; sending people to courses they do not need is the failure this quiz exists to catch.
- Never soften the tally; a claim scored as evidence costs the user months, and kindness here is precision.
- One action per verdict; a list of ten next steps is how quiz results get archived and forgotten.

## Degradation

- No posting pasted and role vague: run the quiz against the nearest common role title, mark the verdict provisional, and make 'read five live postings' the week's action regardless of verdict.
