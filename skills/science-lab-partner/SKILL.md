# Report Outline

*Free gateway skill from the Science Lab Partner bundle by GarphenGate.*

The lab report skeleton on demand: every standard section, what belongs in it, what always sneaks into the wrong one, and the self-check questions that catch it, ready before the blank page wins.

## Procedure

1. **Ask two questions.** What was the experiment (one line), and what format does the course require (sections named in the manual, or default IMRaD-style school format)? The course's stated format always wins.
2. **Issue the skeleton.** Each section with: its one-line job, 2-3 bullets of what belongs, and the classic misplacement to avoid (interpretation in Results, new results in Discussion, procedure re-told in Conclusion).
3. **Tailor one layer.** Slot the student's one-line experiment description into the skeleton so the Introduction and Results bullets name their actual variables rather than placeholders.
4. **Attach the self-checks.** Three questions per key section the student answers before submitting (Results: 'could a reader re-plot my data from what I wrote?'; Discussion: 'did I give my hypothesis a verdict?').
5. **Point forward.** Note that filling the skeleton is the student's writing; deeper reasoning help exists in the full bundle's structurer.

## Output contract

```
LAB REPORT SKELETON — <experiment> (<format>)
Title: claim or question, not 'Lab 4'
Introduction — job: <line> · include: <bullets> · keep out: <classic misplacement>
Method — job: ... · include: ... · keep out: ...
Results — job: ... · include: ... · keep out: ...
Discussion — job: ... · include: ... · keep out: ...
Conclusion — job: one claim-sized paragraph · keep out: <misplacement>
Self-checks before submitting: <3 per key section>
```

## Rules

- Never fill the skeleton with drafted prose for the student; bullets name what belongs, the sentences are theirs.
- Never override the course's required format with the default one; when they differ, the manual wins and the difference is noted.
- Never include a data-adjustment tip of any kind; anomalies belong in Discussion, and the skeleton says so.

## Degradation

Student can't name the required format: issue the default school IMRaD-style skeleton and flag 'check your lab manual's section list against this'. No experiment done yet: issue the generic skeleton and note which sections can be pre-drafted before data exists (Introduction, Method).
