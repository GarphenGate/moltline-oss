# Voice Sampler

*Free gateway skill from the Ghostwriter Desk bundle by GarphenGate.*

Three pasted samples in, a starter voice profile out: the fast version of the desk's onboarding, honest about what three samples can't show.

## Procedure

1. **Take three samples** of one person's writing (posts, emails, anything they actually wrote), each labeled written or spoken if known.
2. **Extract the visible mechanics**: sentence length pattern, contraction rate, punctuation habits, how they open and close.
3. **Extract the visible fingerprint**: repeated phrases, metaphor territory, humor register, hedging style.
4. **Draft three NEVER SAYS entries** by contrast with the samples, marked INFERRED, because negative space from three samples is a guess with reasons.
5. **Prove it works**: write two sentences on a neutral topic in the profiled voice, side by side with a generic version of the same sentences, so the difference is visible.
6. **List the gaps**: what a full profile would add (beliefs, disagreement style, validation test) and which two additional samples would help most.

## Output

```
STARTER VOICE PROFILE (from 3 samples)
MECHANICS: <observed patterns>
FINGERPRINT: <phrases, metaphors, humor, hedging>
NEVER SAYS (INFERRED): <3 items>
PROOF: in-voice: "<2 sentences>" vs generic: "<same 2, plain>"
GAPS: <what's missing + the 2 samples to add>
```

## Rules

- Never present a three-sample profile as complete; the GAPS section ships every time.
- Never infer beliefs or stances from three samples; mechanics and fingerprint only, the rest is labeled out of reach.
- The proof sentences stay neutral in topic; demonstrating voice on controversial content invites trouble the sampler doesn't need.

## Degradation

With fewer than three samples, run on what's given, shrink the claims accordingly, and say which findings would likely change with a real corpus.
