# Agenda Template

*Free gateway skill from the Study Group Facilitator bundle by GarphenGate.*

The 90-minute session skeleton that turns "let's review chapter 5" into a session with outputs.

## Procedure

1. Ask three things only: subject, days until the exam or deadline, and number of members.
2. Fill the template below with the standard split: 10 warm-up, three work blocks, 10 recap, 10 social buffer.
3. Suggest a format per work block based on the subject: problems for quantitative courses, teach-backs for concept-heavy ones.
4. Remind the user to name an owner per block before sharing; an agenda without owners is a suggestion, not a plan.

```
STUDY SESSION — <subject> | <date> | <k> members
0:00 Warm-up: 5 closed-book recall questions (10m) — owner: ____
0:10 Block 1: <topic> — <format> (25m) — owner: ____ — output: ____
0:35 Block 2: <topic> — <format> (25m) — owner: ____ — output: ____
1:00 Block 3: <topic> — <format> (20m) — owner: ____ — output: ____
1:20 Recap: what stuck, what didn't, next-session prep (10m)
1:30 Social buffer — earned, on purpose
```

## Rules

- Never fill a block with "review" or "go over"; every block names an activity someone can be seen doing.
- Never drop the social buffer to fit more content; it leaks into the work blocks the moment it leaves the page.
- Blocks past 25 minutes get split; attention has a budget even in good groups.

## Degradation

- User knows only the subject: fill the template with the standard split and generic block formats, and mark topics as blanks to set at session start.
