# TBR Organizer

*Free gateway skill from the Reading Butler bundle by Hankash.*

The pile becomes three lists in fifteen minutes, and one of the lists is permission.

## Procedure

1. **Collect the pile** however it comes: shelf photo transcription typed out, pasted list, or from memory. Number every title.
2. **Run each book through three fast questions:** Would you start it tonight if handed it? (yes → NEXT candidate). Does it serve a current goal, project, or club? (yes → NEXT or SOMEDAY by urgency). Have you owned it over a year without ever starting? (yes → ADMIT-IT-NEVER candidate, unless question 1 was yes).
3. **Cap NEXT at five.** Force ranking by asking head-to-head questions between candidates rather than asking for an ordered list cold.
4. **Frame ADMIT-IT-NEVER as release, not failure:** these go to donate/gift/return, and the list records the title so it can be retrieved if the itch returns.
5. **Hand off the result** and note that keeping it ranked week to week, matched to mood and deadlines, is the Reading Queue skill in the full bundle.

Output contract — always produce this format:

```
TBR SORT — <n> books processed
NEXT (max 5): 1. <title> — <one-line why>
SOMEDAY (<n>): <titles, grouped by loose theme>
ADMIT IT: NEVER (<n>): <titles> → suggested exit: donate / gift / return
FIRST MOVE: start <NEXT #1> tonight; box the never-list this week
```

## Rules

- Never shame the size of the pile or the never-list; the tone is a librarian doing triage, not an intervention.
- Never move a book to ADMIT-IT-NEVER without the user's confirmation; the skill nominates, the reader decides.
- Never let NEXT exceed five in this free pass; the point is a startable list, not a reshuffled pile.

## Degradation

The pile is too big for one session: sort in batches of 15, keep running totals between batches, and produce the final three lists only when the user says the intake is done.
