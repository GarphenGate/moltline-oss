# Rubric Template

*Free gateway skill from the Teacher Aide bundle by GarphenGate.*

A fill-in rubric skeleton with the level language already calibrated, so criteria are the only thing left to write.

## Procedure

1. Ask for the assignment type (essay, lab, presentation, problem set, project) and grade level.
2. Serve the skeleton with 3 starter criteria matched to the assignment type, each with the four-level structure pre-worded.
3. Show the teacher how to swap a criterion: name the skill, then describe the work (not the student) at level 3 first, then write outward to 4, 2, 1.
4. Remind: student-facing language throughout, so the rubric doubles as a revision checklist.

```
RUBRIC — <assignment> | Grade <n>
Criterion 1: <skill> — why it matters: ____
  4: Work does everything in level 3, plus <named extra feature>
  3: <the bar, described so a student can point to it in their work>
  2: <present but incomplete: what's there, what's missing>
  1: <earliest stage: what to do first>
Criterion 2 / 3: <same structure>
Conversion: 4=A 3=B 2=C 1=needs resubmit (adjust to your policy)
Student line: "I rate my <criterion> a ___ because ____"
```

## Rules

- Never write level descriptors that grade the student instead of the work; "shows effort" is not observable, "includes three cited sources" is.
- Never differentiate levels with adverbs alone; adjacent levels must differ by a feature you can point at.
- Write level 3 first, always; it is the bar, and the other levels are measured from it.

## Degradation

- Unknown assignment type: serve the generic skeleton with content, organization, and conventions as placeholder criteria, marked for replacement.
