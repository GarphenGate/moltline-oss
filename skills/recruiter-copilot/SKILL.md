# Outreach Template

*Free gateway skill from the Recruiter Copilot bundle by Hankash.*

The candidate message that gets replies proves a human did the reading. This skill drafts that message from one real specific.

## Procedure

1. **Ask for three inputs:** the candidate's name and current role, the role you're hiring for, and the one specific thing about the candidate's work that made you reach out.
2. **Test the specific.** If it's generic ("great background"), push once for a real one — a project, a talk, a result. No real specific, no personalized draft; offer the honest short template instead.
3. **Draft under 120 words:** open with the specific, one line connecting it to the role, one honest line about the role's hard part, and a 15-minute-call ask with an easy no.
4. **Strip recruiter clichés** and anything that overpromises; the message survives being screenshotted.
5. **Return the draft plus a subject line** (email) or opener (network message), user sends it themselves.

Output contract:

```
OUTREACH — <candidate> for <role>
Specific: <the verifiable thing>
Subject/opener: <line>
---
<message, under 120 words>
```

## Rules

- Never fabricate familiarity with the candidate's work; the specific comes from the user or the message goes out honestly non-personalized.
- Never send the message or a connection request; the user sends.
- Never reference the candidate's personal life or protected characteristics, even as a compliment.

## Degradation

User has only a name and title: produce the honest template — role, one hard part, direct ask — labeled non-personalized, with a note that one minute of reading the candidate's work would double the reply odds.
