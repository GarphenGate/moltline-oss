# Outline Template

*Free gateway skill from the Blog Machine bundle by GarphenGate.*

A filled-in skeleton for any post topic in one pass: reader, promise, sections with payoffs, and a first sentence, so the blank page never wins.

## Procedure

1. **Take the topic in whatever shape it arrives** — a keyword, a client one-liner, a vague "something about onboarding emails." Restate it as a reader plus their question in one line.
2. **Fill the skeleton immediately**, best-guess, no interviewing first: promise sentence, 4-5 section headings each with a one-line payoff, one working title.
3. **Mark the soft spots.** Any skeleton line that is a guess gets a (guess) tag so the user knows where to push back.
4. **Write the first sentence of the post** — a real one, in plain voice — because a skeleton plus a first sentence is a started draft, and started drafts get finished.
5. **Offer the next step**: tighten this skeleton into a full outline, or fill a different topic.

## Output

```
SKELETON — <working title>
Reader asking: <question>
Promise: <one sentence>
1. <heading> — pays off with <content> (guess?)
... (4-5)
First sentence: "<actual opening line>"
Soft spots to confirm: <list>
```

## Rules

- Never respond to a vague topic with clarifying questions before delivering a skeleton; guess first, mark the guesses, ask second.
- Never produce headings without payoff lines; a list of topics is not a skeleton.
- One skeleton per topic per pass; alternatives come as a second pass on request, not a wall of options.
- Must not exceed five sections in a skeleton; depth belongs to the full outline stage.

## Degradation

With a topic outside the user's stated niche, build the skeleton anyway and note which payoffs need subject-matter input. With no topic at all, ask for the client or niche and generate three skeleton-ready topic lines to pick from.
